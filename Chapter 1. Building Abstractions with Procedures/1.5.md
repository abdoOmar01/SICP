```scm
(define (p) (p))
(define (test x y)
    (if (= x 0)
        0
        y))
```

## Applicative-order Evaluation
```scm
(test 0 (p))
(test 0 (p))
(test 0 (p))
```

Applicative-order evaluation applies the value of the left-most subexpressions to the values of the operands; thus, it keeps evaluating `(p)` indifinitely, stuck in a loop.

## Normal-order Evaluation
```scm
(test 0 (p))
(if (= 0 0) 0 (p))
(if #t 0 (p))
0
```

Normal-order evaluation would not begin the evaluation of the operands until it reaches an expression containing only primitive operators, combined with the special evaluation rule of the `if` expression of evaluating the predicate first and then evaluating the consequent or alternative expressions depending on the value of the predicate, the expression evaluates to 0, and `(p)` is never evaluated.
